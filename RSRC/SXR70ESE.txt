      * Description:  This is a new online program SXR70ESE from which  
      * the user chooses to maintain Shore Excursion Records. Shore 
      * Excursion Maintenance will display a screen that provides the   
      * user with the options to:   
      * > Search for Shore Excursions based on combination  
      *   of ShoreExId or Port or Operator Code .   
      * 
      * The system will provide the user with search options for
      * locating Excursion(s).  
      * The user will have the following options:   
      * > Find Shore Excursion using Shore Excursion ID.
      * > List Shore Excursions by specific Port Name (system defaults  
      *   to All Ports) and/or Tour Operator.   
      * > Also from Shore Excursion Management Screen if a particular   
      *   Shore Ex is selected then this program will give the detail   
      *   for that Shore Ex.
      * The possible values for Shorexid, port_of_call and vendor_id are
      * either "Blank" or "Some value". 
      * 
      * So we have 8 cases for searching a shore excurion (Listing):
      * ---|-----------|--------------|-----------|---------------------
      * Sr.| ShoreExID | Port_of_Call | Vendor_id | Show records
      * ---|-----------|--------------|-----------|---------------------
      * 1) |   Blank   |    Blank     |   Blank   | All 
      * 2) |   Blank   |    Value     |   Blank   | Specific Port   
      * 3) |   Blank   |    Value     |   Value   | Specific Port & Vend
      * 4) |   Value   |    Blank     |   Blank   | Specific ShoreExID  
      * 5) |   Value   |    Value     |   Blank   | Specific ShoreExID  
      * 6) |   Value   |    Blank     |   Value   | Specific ShoreExID  
      * 7) |   Value   |    Value     |   Value   | Specific ShoreExID  
      * 8) |   Blank   |    Blank     |   Value   | Specific Vendor-ID
