       PROCEDURE DIVISION.  

       1000-INITIALIZE. 
           COPY DPP01INT.   

           ACCEPT WS-SYSTEM-DATE  FROM DATE YYYYMMDD.   
           ACCEPT WS-SYSTEM-TIME  FROM TIME.

           PERFORM DPP12-BEGIN-THREAD THRU DPP12-BEGIN-THREAD-EXIT. 

           IF DPP01-SQL-ERROR-IND = 'Y' 
              GO TO DPP12-THREAD-ERROR-EXIT.

           IMPART.  

           OPEN EXCINV01 USAGE-MODE  IS RETRIEVAL   
                EXCINV02 USAGE-MODE  IS RETRIEVAL   
                EXCINV03 USAGE-MODE  IS RETRIEVAL   
                EXCINV04 USAGE-MODE  IS RETRIEVAL   
                EXCINV05 USAGE-MODE  IS RETRIEVAL   
                EXCINV06 USAGE-MODE  IS RETRIEVAL   
                EXCINV07 USAGE-MODE  IS RETRIEVAL   
                EXCINV08 USAGE-MODE  IS RETRIEVAL   
                EXCINV09 USAGE-MODE  IS RETRIEVAL   
                EXCINV10 USAGE-MODE  IS RETRIEVAL   
                EXCINV11 USAGE-MODE  IS RETRIEVAL   
                EXCINV12 USAGE-MODE  IS RETRIEVAL   
                ETRF     USAGE-MODE  IS RETRIEVAL   
                EXCURSION USAGE-MODE IS RETRIEVAL   
                EXCORDER0 USAGE-MODE IS RETRIEVAL   
                EXCORDER1 USAGE-MODE IS RETRIEVAL   
                EXCORDER2 USAGE-MODE IS RETRIEVAL   
                EXCORDER3 USAGE-MODE IS RETRIEVAL   
                EXCORDER4 USAGE-MODE IS RETRIEVAL   
                EXCORDER5 USAGE-MODE IS RETRIEVAL   
                EXCORDER6 USAGE-MODE IS RETRIEVAL   
                EXCORDER7 USAGE-MODE IS RETRIEVAL   
                EXCORDER8 USAGE-MODE IS RETRIEVAL   
                EXCORDER9 USAGE-MODE IS RETRIEVAL.  

           OPEN INPUT  INPUT-FILE.  
           OPEN OUTPUT OUTPUT-FILE. 

           READ INPUT-FILE  
              AT END GO TO 9000-END-OF-JOB. 
           MOVE INPUT-BEG-DATE         TO WS-TEMP-START-DATE.   
           MOVE INPUT-END-DATE         TO WS-TEMP-END-DATE. 

       1020-BUILD-ESDR-FILE.
           MOVE 'EXCINV'               TO EXCINV-CALCAREA (1:6).
           MOVE 00                     TO WS-AREA-NUM.  

       1040-FETCH-EMYR. 
           IF WS-AREA-NUM < 12  
              ADD 1                    TO WS-AREA-NUM   
           ELSE 
              GO TO 1180-ESDR-EXIT  
           END-IF.  

           MOVE WS-AREA-NUM            TO EXCINV-CALCAREA (7:2).

       1060-FETCH-FIRST-EMYR.   

           FETCH FIRST EXC-MMYY-REC WITHIN  
              EXCINV-CALCAREA AREA  
              ON ERROR GO TO 1100-EMYR-ERR. 

           GO TO 1100-EMYR-ERR. 

       1080-FETCH-NEXT-EMYR.

           FETCH NEXT EXC-MMYY-REC WITHIN   
              EXCINV-CALCAREA AREA  
              ON ERROR GO TO 1100-EMYR-ERR. 

       1100-EMYR-ERR.   

           IF ERROR-NUM NOT = '0000'
              GO TO 1040-FETCH-EMYR 
           END-IF.  

       1120-VALIDATE-EMYR.  
           IF EMYR-EXC-YYYY >= WS-TEMP-START-YEAR AND   
              EMYR-EXC-YYYY <= WS-TEMP-END-YEAR 
              CONTINUE  
           ELSE 
              GO TO 1080-FETCH-NEXT-EMYR
           END-IF.  

           IF EMYR-EXC-YYYY = WS-TEMP-START-YEAR
              IF EMYR-EXC-MM >= WS-TEMP-START-MM
                 CONTINUE   
              ELSE  
                 GO TO 1080-FETCH-NEXT-EMYR 
              END-IF
           END-IF.  

           IF EMYR-EXC-YYYY = WS-TEMP-END-YEAR  
              IF EMYR-EXC-MM <= WS-TEMP-END-MM  
                 CONTINUE   
              ELSE  
                 GO TO 1080-FETCH-NEXT-EMYR 
              END-IF
           END-IF.  

       1140-FETCH-EDR.  

           FETCH NEXT EXC-DEPARTURE-REC 
              WITHIN EXC-MMYY-DEPARTURE-SET SET 
              SUPPRESS AREA CURRENCY
              ON ERROR GO TO 1140-FETCH-EDR-ERROR.  

       1140-FETCH-EDR-ERROR.

           IF ERROR-NUM NOT = '0000'
              GO TO 1080-FETCH-NEXT-EMYR
           END-IF.  

           MOVE EDR-CALC-KEY           TO WS-EDR-CALC-KEY.  

           IF WS-EDR-BEGIN-DATE >= WS-TEMP-START-DATE   
              CONTINUE  
           ELSE 
              GO TO 1140-FETCH-EDR  
           END-IF.  

           IF WS-EDR-BEGIN-DATE < WS-TEMP-END-DATE  
              CONTINUE  
           ELSE 
              GO TO 1140-FETCH-EDR  
           END-IF.  

       1160-FETCH-ESDR. 

           FETCH NEXT EXC-SAILING-DEPARTURE-REC 
              WITHIN EXC-DEPARTURE-SAILING-SET SET  
              SUPPRESS AREA CURRENCY
              ON ERROR GO TO 1160-FETCH-ESDR-ERROR. 

       1160-FETCH-ESDR-ERROR.   

           IF ERROR-NUM NOT = '0000'
              GO TO 1140-FETCH-EDR  
           END-IF.  

           MOVE ESDR-CALC-KEY          TO WS-ESDR-CALC-KEY. 

           IF WS-ESDR-EXC-DATE >= WS-TEMP-START-DATE
              CONTINUE  
           ELSE 
              GO TO 1160-FETCH-ESDR 
           END-IF.  

           IF WS-ESDR-EXC-DATE < WS-TEMP-END-DATE   
              CONTINUE  
           ELSE 
              GO TO 1160-FETCH-ESDR 
           END-IF.  

           MOVE WS-ESDR-EXC-ID         TO EMR-EXC-ID.   
           FETCH EXC-MASTER-REC RECORD  
              ON ERROR GO TO 1160-FETCH-ESDR.   

           MOVE ESDR-CALC-KEY          TO OUT-ESDR-CALC-KEY.
           MOVE ESDR-EXC-TIME          TO OUT-ESDR-EXC-TIME.
           MOVE ESDR-STATUS            TO OUT-ESDR-STATUS.  
           MOVE EMR-PORT-CODE          TO OUT-PORT-CODE.
           MOVE ESDR-EXC-END-TIME      TO OUT-ESDR-EXC-END-TIME.
           MOVE ESDR-EXC-END-DATE      TO OUT-ESDR-EXC-END-DATE.

           IF ESDR-SAIL-DATE = ESDR-EXC-DATE
              MOVE 'E'                 TO OUT-ESDR-PORT-TYPE
           ELSE 
              MOVE ESDR-DURATION-DAYS  TO DPP02-NUMBER-DAYS 
              MOVE ESDR-SAIL-DATE      TO DPP02-YYYYMMDD-DATE   
              PERFORM DPP10-ADVANCE-YYYYMMDD-DATE   
              IF DPP02-YYYYMMDD-DATE = ESDR-EXC-DATE
                 MOVE 'D'              TO OUT-ESDR-PORT-TYPE
              ELSE  
                 MOVE 'P'              TO OUT-ESDR-PORT-TYPE
              END-IF
           END-IF.  

           WRITE OUTPUT-REC.

           GO TO 1160-FETCH-ESDR.   

       1180-ESDR-EXIT.  
           EXIT.

       9000-END-OF-JOB. 
           CLOSE INPUT-FILE 
                 OUTPUT-FILE.   

           GO TO DPP12-END-OF-JOB.

           GO TO DPP12-DATABASE-ERROR.

           PERFORM DPP12-EDIT-ERROR-MSG 
              THRU DPP12-EDIT-ERROR-MSG-EXIT.   

           GO TO DPP12-END-OF-JOB.

           PERFORM DPP12-EDIT-ERROR-MSG 
              THRU DPP12-EDIT-ERROR-MSG-EXIT.

           GO TO DPP12-SEVERE-ERROR-MSG.

       9400-INFO-MSG.   
           PERFORM DPP12-INFO-MSG   
              THRU DPP12-INFO-MSG-EXIT. 

       9500-RETURN-SUBROUTINE-ERROR.
           GO TO DPP12-RETURN-SUBROUTINE-ERROR.

           PERFORM DPP12-SAVE-SUBROUTINE-MSGS   
              THRU DPP12-SAVE-SUBROUTINE-MSGS-X.
